What it does

A population of 20 networks flies the same course at the same time. A bird earns 0.1 per frame alive and 5 for each pipe passed, and loses 1 for hitting a pipe. Fitness is distance in practice. The next generation is bred from the best of them.

How this repo does it

flappy.py hands that loop to neat-python. This page re-implements the game rules and the NEAT steps (speciation, stagnation, elitism, crossover, add/delete node and connection) in JavaScript and reads the same config.txt.

Reading the chart

Best fitness is not monotonic. Pipe heights are random every generation, so a good network can meet a harder course and score less. A run that stays at 1 or 2 pipes for a while is normal with 20 birds.

Honest caveat. The game images are not in the repository, so sprite sizes are assumed from the usual tutorial art (bird 68×48 after doubling, pipe 104 wide). Collision uses rectangles; the original uses pixel masks. A generation also ends as soon as one bird reaches fitness_threshold, because training would stop there. The Config and checks tab lists what was compared against the Python code and how closely it matched.

What it does

The same game step the networks use: a flap sets velocity to −10.5, then each frame moves the bird by v·t + 1.5·t², capped at 16 pixels down. Pipes move 5 pixels per frame at 30 frames per second.

How this repo does it

flappy.py has no keyboard control; only the NEAT networks fly. This mode is new on this page, built on the same engine, so you can feel what the networks are solving.

Racing

With the race switched on, the best network from the Evolve tab flies the same pipes beside you. It has no memory between frames: it only sees the bird's height and the distance to the gap edges.

Config and checks

What the page reads from config.txt, which game rules it copies from flappy.py, and how its results compare with the Python code.

The network's three inputs and one output

bird.yThe bird's height in pixels.
abs(bird.y − pipe.height)Distance to the top edge of the next gap.
abs(bird.y − pipe.bottom)Distance to the bottom edge of the next gap.
output[0] > 0.5Flap. With tanh the output lies between −1 and 1.

The inputs are raw pixel values, not scaled. With tanh(2.5·z) that saturates quickly, which is part of why this setup learns slowly.

Read these with care. Each engine uses its own random number generator, so single runs differ; only the distributions are comparable. Both use seeds 0 to 99 and the config.txt in this repository. Reaching fitness 200 inside 20 generations is rare with this configuration, which is why the Evolve tab lets you run past the 20-generation cap that flappy.py uses.
